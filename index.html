무한 생일 파티 모드

휴대폰 발열·배터리를 고려해 화면에 동시에 표시되는 개수는 제한돼.

📨 생일 메시지 발송 센터

문자 · 이메일 · 인스타그램 및 설치된 공유 앱

중요! 연락처 전체에 무단 자동 발송하는 기능은 없으며, 각 메신저의 보안 정책을 준수해요. 이 화면에서 문자는 메시지 작성창, 메일은 이메일 작성창을 열고 최종 전송은 직접 확인해요. 자동 외부 발송은 아래 GitHub Actions를 별도로 설정한 경우에만 작동해요.

📱

전화번호로 문자 보내기

선택한 전화번호로 생일 축하 메시지가 작성된 문자 앱을 열어요. 실제 발송은 문자 앱에서 확인!

일반 웹사이트는 문자 앱을 대신해 자동으로 전송 버튼을 누를 수 없어요.
📧

이메일로 축하 보내기

생일 축하 메시지가 들어 있는 메일 작성창을 열어요. 받는 사람을 확인하고 전송!

자동 이메일 발송은 별도의 발송 서비스와 계정 인증이 필요해요.
📸

인스타그램 DM으로 공유

문구를 복사하고 인스타그램 DM 화면을 열어요. 상대방을 골라 붙여 넣으면 끝!

인스타그램 개인 계정에 임의로 DM을 자동 발송하는 것은 지원하지 않아요.
🌍

가능한 모든 공유 앱

휴대폰 공유 메뉴에서 설치된 카카오톡 · 문자 · 인스타그램 등 지원하는 앱을 골라 전송해요.

앱별 지원 여부는 기종과 브라우저에 따라 달라질 수 있어요.
⚙️

실제 자동 발송 연결하기

GitHub 저장소의 Actions에 생일 당일 동의한 대상 1명에게 이메일과 문자를 각각 1회 보내는 워크플로를 준비했어요. 자동 전송을 시작하려면 발송 서비스 계정과 비밀키를 직접 설정해야 하며, Instagram DM 자동 발송은 포함되지 않아요.
